# Usage

Muffin turns the folders of Markdown files in `content/` into a static website
inside `muffin/`.

Run these commands from the project root:

- **Build:** `npx tsx build.ts`
- **Test:** `npm test`

Point Muffin at a vault, commit the generated site, and adjust the theme tokens
in your site configuration to make it your own. Back to [[Home]].
